# Leticia Hermoso de Agar — Portfolio

Personal portfolio site for my work as a Senior Cinematic & Layout Artist in AAA games and film/VFX.

**Live site:** https://lehegar.github.io/portfolio_Leticia_Hermoso/

## About

Cinematic and layout artist with 6+ years in AAA games and feature films, working mainly in Unreal Engine 5 and Maya — from previs and camera work through to final shots. This site gathers my reels, selected credits and toolset.

## Built with

Plain HTML, CSS and JavaScript, no frameworks. Reels are embedded from Vimeo.

## Structure

- `index.html` — page content
- `style.css` — styles
- `script.js` — small interactions (scroll reveal, sticky header, custom cursor)
- `imagenes/` — project thumbnails and studio logos

## Running locally

Open `index.html` in a browser, or serve the folder with a live server for auto-reload while editing.
